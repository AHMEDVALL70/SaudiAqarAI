# 🏛️ SaudiAqarAI - المنصة الذكية لتقييم العقارات السعودية

منصة تفاعلية مدعومة بالذكاء الاصطناعي لتقييم وتوقع أسعار العقارات في مختلف مدن وأحياء المملكة العربية السعودية.

## 🚀 المميزات
- **نموذج تقديري حقيقي:** يعتمد على المؤشرات الحقيقية للسوق العقاري السعودي.
- **معالجة محلية سريعة:** تعتمد على خوارزميات تعمل على متصفح المستخدم بمرونة وأمان كامل.
- **واجهة مستخدم فاخرة:** متجاوبة بالكامل ودعم للهوية السعودية والعرض الداكن.
