# 🏠 عقارAI — منصة توقع أسعار العقار السعودية

منصة ذكاء اصطناعي لتقييم العقارات بالسعودية، مبنية على أسلوب مشروع [AhmedVall PropAI](https://github.com/AHMEDVALL70/AhmedVall_PropAI) (قطر) — ملف واحد، بدون Docker أو قاعدة بيانات، بنشر مجاني بالكامل.

## 🚀 التشغيل الفوري (بدون أي تثبيت)

افتح `index.html` مباشرة بالمتصفح — كل شي شغال محلياً:
- لوحة تحكم بمؤشرات السوق
- محرك بحث وتصفية للعقارات
- تقييم فوري لأي عقار (معادلة ذكية حسب الحي)
- تصدير PDF / CSV
- مستشار عقاري بردود جاهزة (بدون اتصال إنترنت للـ AI)

> ملاحظة: كل الأسعار والبيانات بالمشروع **تقديرية توضيحية**، مو بيانات رسمية حية. حدّثها من مصدر موثوق مثل الهيئة العامة للعقار (REGA) أو منصة عقار/إيجار.

## 🌐 النشر على الإنترنت مجاناً (GitHub Pages)

1. ارفع محتوى هذا المجلد لمستودع GitHub جديد
2. من إعدادات المستودع: Settings → Pages → فعّل GitHub Pages على فرع main
3. رابطك بيصير: `https://username.github.io/repo-name/`

## 🤖 تفعيل المستشار الذكي الحقيقي (اختياري)

بدون إعداد إضافي، المستشار الذكي يشتغل بـ"ردود جاهزة" محلية. لتفعيل ردود حقيقية عبر Claude API:

### الخطوة 1: نشر الخادم الخلفي على Cloudflare Workers (مجاني)

```bash
npm install -g wrangler
wrangler login
wrangler secret put ANTHROPIC_API_KEY   # الصق مفتاحك sk-ant-... عند الطلب
wrangler deploy
```

سيعطيك رابطاً شبيهاً بـ: `https://aqarai-backend.YOUR-SUBDOMAIN.workers.dev`

### الخطوة 2: ربط الموقع بالخادم

افتح `index.html`، ابحث عن:
```js
const PROXY_URL = 'https://REPLACE-WITH-YOUR-WORKER-URL.workers.dev/chat';
```
واستبدله برابطك الفعلي + `/chat`.

### الخطوة 3 (مهمة أمنياً): قيّد الوصول لدومين موقعك فقط

في `worker.js`:
```js
const ALLOWED_ORIGIN = "*";
```
غيّرها لدومين موقعك الفعلي بعد التأكد أن كل شيء يعمل:
```js
const ALLOWED_ORIGIN = "https://your-username.github.io";
```
ثم أعد النشر: `wrangler deploy`

## ✅ مراجعة أخطاء مشروع قطر (بناءً على ملاحظات فعلية)

| الملاحظة | الحالة بنسخة عقارAI |
|---|---|
| مفتاح Claude API مكشوف مباشرة بالكود | **غير وارد أصلاً** — النسخة مبنية من البداية على `worker.js` فقط، بدون أي "خيار احتياطي" يحوي مفتاح API بالمتصفح |
| منطق سعر صامت للمناطق غير المعروفة (بدون تنبيه) | **تم إصلاحه** — أي منطقة غير موجودة بقاعدة البيانات يظهر معها تنبيه صريح `⚠️` للمستخدم يوضح إن الرقم تخميني وقد يكون غير دقيق |
| بيانات أسعار قديمة/تقديرية مو حية | **موجود ومُوثّق بوضوح** بكل مكان بالمشروع (الجدول، المستشار الذكي، هذا الملف) أنها تقديرية للتوضيح، مع رابط `DATA_SOURCE_URL` جاهز لربطها ببيانات حقيقية لاحقاً |

## 🔧 إصلاح مهم مقارنة بمشروع قطر الأصلي

نسخة قطر الأصلية فيها خطأ: الواجهة كانت ترسل `{message, language, history}` بينما
`worker.js` يتوقع `{system, messages}` — يعني وضع "الاتصال الآمن" كان يفشل دائماً بخطأ 400.
تم إصلاح هذا في نسخة عقارAI: الواجهة الآن تبني `messages` بصيغة Claude API الصحيحة
(مصفوفة `{role, content}`) وترسل `system` بشكل منفصل، متوافقة تماماً مع `worker.js`.

## 📝 تحديث بيانات العقارات ببيانات حقيقية

الموقع يحاول تلقائياً تحميل `properties.json` من رابط GitHub Raw معرّف بمتغير
`DATA_SOURCE_URL` داخل `index.html`. لو رفعت ملف `properties.json` بنفس تنسيق
`PROPERTIES_DB` (id, zone, type, size, beds, price, pred, status, cls, desc)
لمستودعك، حدّث الرابط ليشير له وبيتحدث الموقع تلقائياً بالبيانات الحقيقية.

## ⚠️ تنبيه مهم

- بيانات الأسعار بالمشروع **تقديرية للتوضيح فقط**، ماخوذة من فهم عام لمستويات السوق، مو من تقرير رسمي منشور.
- قبل الاستخدام الفعلي أو النشر التجاري، حدّث `SAUDI_ZONES_DB` و`PROPERTIES_DB` و`SYSTEM_PROMPT_AR/EN` ببيانات موثقة من مصدر رسمي.
- رقم الواتساب والبريد الإلكتروني بقسم "تواصل معنا" أرقام توضيحية عامة — لازم تستبدلها ببياناتك الفعلية قبل النشر.
